# Yngin

Yngin is a game engine project that I'm building for fun. This is a personal project that I work on in my free time.

## Features
- 🗺️ Editor
- 📜 Scripting
- 🗿 Model Loading
- 🖼️ Scenes
- 📱 UI

## Supported Platforms
At the moment, Windows is the only supported platform.

## Building
### Requirements
- Visual Studio 2022
- Desktop development with C++

### Steps
1. Clone this repository
2. Select the "Editor" project as the startup project
3. Build
